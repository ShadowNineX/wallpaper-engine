## One schema. A shorter path to your desktop.

Define the controls once. Their types follow you into the wallpaper, and the
Vite plugin handles the editor metadata around them.

<ol class="we-doc-flow">
  <li><strong>Define once</strong><p>Describe colors, sliders, files, and other controls in one typed property record.</p></li>
  <li><strong>Preview in the browser</strong><p>Send properties, audio, and media to your wallpaper from the development simulator.</p></li>
  <li><strong>Build for the host</strong><p>Vite emits your assets and <code>project.json</code>. Check the result in Wallpaper Engine.</p></li>
</ol>

## Start with something you can see

Each example includes the page, the runtime code, and the Vite configuration.
Pick a result, copy the files, and start changing things.

## Start building

- [Install the package](./getting-started/installation/) and choose the entry points your wallpaper needs.
- [Complete the typed quick start](./getting-started/quick-start/).
- Build an audio visualization or media card from the [complete examples](./examples/).
- Browse the [API reference](./reference/) for exact public signatures.
- Study the [consumer demo source](https://github.com/ShadowNineX/wallpaper-engine/tree/main/demo/src).
